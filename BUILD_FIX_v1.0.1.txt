NewCore v1.0.1 - build fix

Fixed the Zig build failure:
  error: the argument -femit-implib is allowed only when building a Windows DLL

Cause in v1.0.0 build.cmd:
  -Wl,--out-implib,dist\libThanLongNewCoreBridge.a

The controller does not link against an import library. It loads the bridge with
LoadLibraryW/GetProcAddress, so generating an import library is unnecessary.

v1.0.1 changes:
- Removed --out-implib entirely.
- Builds the bridge DLL in the project root, then moves it into dist.
- Cleans any unused .lib/.a side products.
- Prints Zig version and warns when it is not 0.15.2.
- Gives explicit stage labels and output existence checks.
